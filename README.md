# Offer 求你看看我

一个把「岗位表」变得好筛的小工具。秋招海投季，表里两千个岗位，我只想三秒找到我能投的那几个。

👉 **在线使用：https://josearmandodeh-ux.github.io/offer-pls-look-at-me/**

## 能干嘛

- 📂 把岗位表（CSV / Excel）拖进来就能用，自动识别「公司 / 岗位 / 工作地点 / 届次 / 招聘类型 / 截止日期 / 投递链接」等常见列名
- ⚡ 一键预设：GTM / 商业化 / 海外、市场运营、产品经理、战略分析、AI 公司、免笔试快速投
- 🔍 关键词搜岗位，也能排除关键词（比如把「算法 嵌入式 硕士」踢掉）
- 🎛 按届次、城市、行业、笔试、学历、发布时间组合筛选（选了城市会自动带上「全国各地」）
- ⭐ 收藏 / ✅ 已投递，顺手当投递进度表；结果和收藏都能导出 CSV

## 隐私

纯前端单页，表格只在你自己的浏览器里解析，**不会上传到任何服务器**。收藏和投递状态存在浏览器本地。

## 关于数据

本仓库**不包含任何岗位数据**，只有工具本身和一份虚构的示例数据（`sample.csv`）。

作者自用的数据来源：楼主在互联网某个神秘角落斥巨资购得的岗位表。版权归原作者所有，所以不在这里公开，想要的话请自己去买 / 自己整理 🙂

## 本地运行

直接双击 `index.html` 就能用（「示例数据」按钮需要通过网页访问才能加载）。
